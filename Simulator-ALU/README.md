# 16-Bit ALU Visualizer

An interactive web application that demonstrates how a computer's processor performs math and logic operations. This tool simulates a 16-bit Arithmetic Logic Unit (ALU)—the "calculator" inside a computer CPU—showing step-by-step how numbers are altered by changing control switches.

---

## Features

- **Easy-to-Use Controls:** Input regular numbers and toggle simple checkboxes to see how the computer processes data in real-time.
- **Dual Number Views:** See numbers as standard decimals and as 16-bit binary sequences (the `0`s and `1`s computers actually read).
- **Step-by-Step Breakdown:** Watch your inputs flow through 4 clear stages of processing, making it easy to understand how complex computing happens from basic logic gates.
- **Status Flags:** See how the processor detects special conditions, like when an answer is exactly zero or a negative number.
